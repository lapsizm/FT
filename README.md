
## Описание

Проект `FileTerrorist` представляет собой утилиту на языке C++, которая рекурсивно переименовывает файлы в указанной директории, добавляя к их именам префикс `"IS_TERRORED"`. Утилита также может прерываться и корректно завершаться при получении сигнала прерывания (SIGINT).

## Функционал

- **Синглтон**: Класс `FileTerrorist` реализует паттерн синглтона, что обеспечивает существование только одного экземпляра этого класса.
- **Рекурсивное переименование файлов**: Утилита проходит по всем файлам в указанной директории и переименовывает их, добавляя префикс `"IS_TERRORED"`.
- **Обработка сигналов**: При получении сигнала прерывания (например, CTRL+C), программа корректно завершает свою работу.
- **Параллельная обработка**: Переименование файлов выполняется в параллельных потоках для ускорения обработки.

## Установка

Для сборки и запуска этого проекта вам понадобятся:

- Компилятор C++ (например, `g++` или `clang++`).
- C++17 для поддержки современных стандартов и библиотек.

### Сборка проекта

1. Сохраните код в файл `FileTerrorist.hpp`.

2. Создайте файл `main.cpp`, который использует `FileTerrorist`, например:

    ```cpp
    #include "FileTerrorist.hpp"

    int main(int argc, char* argv[]) {
        if (argc < 2) {
            std::cerr << "Usage: " << argv[0] << " <directory_path>" << std::endl;
            return 1;
        }

        FileTerrorist *ft = FileTerrorist::GetInstance();
        ft->Start(argv[1]);

        return 0;
    }
    ```

3. Скомпилируйте проект:

    ```bash
    g++ -std=c++17 -o file_terrorist main.cpp
    ```

## Использование

После сборки выполните программу, передав путь к директории, в которой вы хотите произвести переименование файлов:

```bash
./file_terrorist /path/to/directory
```

Программа рекурсивно обойдет все файлы в указанной директории и переименует их, добавив префикс `"IS_TERRORED"`.

## Обработка сигналов

Для корректного завершения работы программы при получении сигнала прерывания (SIGINT), просто нажмите `CTRL+C`. Программа выведет сообщение и завершит выполнение.

## Примечания

- Будьте осторожны при использовании этой утилиты, так как она изменяет имена файлов. Убедитесь, что вы тестируете программу в безопасной среде.
- Программа может занять значительное время для обработки больших деревьев каталогов.
